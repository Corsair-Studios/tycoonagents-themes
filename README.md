# TycoonAgents Themes

Official theme downloads for the [TycoonAgents](https://github.com/Corsair-Studios/TycoonAgents) VS Code extension.

Each theme is a self-contained `.zip` you download from this repo's [Releases](../../releases) page and then import into the extension. Themes reskin the TycoonAgents panel — characters, objects, badges, and environment art — around a visual concept.

## How to install

1. Go to the [Releases](../../releases) page and download the `.zip` for the theme you want.
2. Open the TycoonAgents panel in VS Code (or your VS Code-family IDE).
3. Open the **Theme Picker** and choose **Import .zip**, then select the file you just downloaded.

That's it — the theme is now available locally.

**Important:** the TycoonAgents extension does **not** fetch themes over the network on its own. There is no one-click install. Importing a theme is a local file operation: you download the `.zip` yourself from this repo, then point the extension at that file. Nothing is downloaded automatically, and nothing here is installed without you explicitly choosing it in the Theme Picker.

> **Note:** *Survivors vs Zombies* is already bundled with a fresh install of the TycoonAgents extension. You don't need to download it from here unless you want to reinstall it manually.

## What's in a theme

Each theme `.zip` contains:

- The theme **manifest** (metadata, item names/descriptions, layout).
- **Sliced animation frames**, ready for the extension to render directly.
- The **images** referenced by the manifest (objects, characters, badges, environment art).

Raw, pre-slice source art is deliberately excluded from these downloads to keep file sizes small. What you get is exactly what the extension needs to run the theme — nothing extra.

## Contributing / submitting a theme

Have an idea for an original theme? Open an [issue](../../issues) describing the concept, and we'll follow up.

This repository hosts **only original, IP-clean themes** — art and concepts created for TycoonAgents, with no use of existing franchises, characters, or copyrighted material. Themes based on existing intellectual property will not be accepted here.
