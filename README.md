# TycoonAgents Themes

Themes reskin the TycoonAgents panel, the VS Code view that shows your AI agents at work, with new characters, objects, badges, and environment art. Each theme is a single `.zip` that you download and import into the extension.

## Survivors vs. Zombies

![Survivors vs. Zombies preview](https://github.com/user-attachments/assets/b12e42fe-cf2c-4f74-98de-4be9f4c7a5a2)

A group of survivors build objects in their camp to fight off zombie invaders.

### What's included

- The theme manifest (metadata, item names and descriptions, layout)
- 16 survivor characters, 4 zombie rivals, 21 buildable objects, 9 decor items, and 25 badges
- Sliced animation frames, ready for the extension to render
- The images the manifest references: objects, characters, badges, and environment art

### Install

1. Open this repository's [Releases](../../releases) page and download `survivors_vs_zombies.zip` from the **Survivors vs. Zombies Theme** release.
2. Open the TycoonAgents panel in VS Code.
3. Open the Theme Picker and choose **Import .zip**.
4. Select the file you downloaded. The theme is added to your local theme library, and you can pick it like any other theme.

Importing is a local file operation. TycoonAgents never downloads themes on its own, so nothing is installed until you choose the file.

### Compatibility

Requires the TycoonAgents extension for VS Code. The theme does not state a minimum extension version.
